# ST Hotel ໄລຍະ 5 (ຮ້ານອາຫານ/ບາ/ບໍລິການ → ບິນຫ້ອງ) — ແຜນການສ້າງ

> ເຮັດແບບ Native ໃນ session ດຽວ (ເຈົ້າຂອງສັ່ງ "ເລີ່ມໄລຍະ 5"): ແຕ່ລະ Task = ເທສລົ້ມກ່ອນ → ໂຄ້ດ → ເທສຜ່ານ → commit. **ຍັງບໍ່ push / ບໍ່ deploy.**

**Goal:** (1) ຮ້ານອາຫານ/ບາ ຈ່າຍແບບ **"ຕິດບິນຫ້ອງ"** ໃນໜ້າຮັບເງິນເດີມ; (2) ກາຕາລັອກບໍລິການ (ຊັກລີດ, ທົວ, ເຊົ່າ, ລົດຮັບສົ່ງ, ສະປາ, ສະລອຍນ້ຳ, ຫ້ອງປະຊຸມ, ມິນິບາ) + ໃບສັ່ງບໍລິການ → ບິນຫ້ອງ ພ້ອມການຈອງເວລາ/ຄວາມຈຸ; (3) ລາຍຊື່ອາຫານເຊົ້າ.
**Spec:** ການອອກແບບຂໍ້ 5 (`htSvc`, `htSvcRes`), 6 (ຮ້ານອາຫານ→ບິນຫ້ອງ), 7.5. ໂມດູນ: `htFnb`, `htSvc`, `htSpa`, `htPool`, `htEvent`, `htRetail` (ເປີດ/ປິດໄດ້).

## ການຕັດສິນຂອງຜູ້ສ້າງ
- **ຕິດບິນຫ້ອງ** = ວິທີຈ່າຍໃໝ່ (ສະເພາະໂໝດໂຮງແຮມ + ໂມດູນ htFnb). ເລືອກແຂກທີ່ພັກຢູ່ → ບິນ POS ບັນທຶກ `bill.room`, ບໍ່ນັບເປັນເງິນສົດ/ໂອນໃນກະ (`payKind='room'`), ເພີ່ມແຖວ `dept:'fnb'` ໃນບິນຫ້ອງ (id ຕາຍຕົວ `hx_pos_<ເລກບິນ>`). Void ບິນ POS → void ແຖວໃນບິນຫ້ອງ (ຖ້າ check-out ແລ້ວ → void ບໍ່ໄດ້).
- ຍອດຂາຍຂອງຮ້ານອາຫານນັບໃນລາຍງານ POS ຕອນຂາຍ; ຕອນຮັບເງິນຈິງຢູ່ບິນຫ້ອງ (ລາຍງານລວມໂຮງແຮມ ເຮັດໄລຍະ 6 ຕ້ອງບໍ່ນັບຊ້ຳ).
- **Room service / QR ໃນຫ້ອງ:** ໃຊ້ "ໂຕະ" ທີ່ຕັ້ງຊື່ `ຫ້ອງ 101` (ໂຕະ ແລະ QR ເດີມ) → ຕອນຈ່າຍ ລະບົບເລືອກແຂກຂອງຫ້ອງນັ້ນໃຫ້ເອງ. ບໍ່ສ້າງລະບົບໃໝ່.
- **ບໍລິການ:** ກາຕາລັອກ `htSvc` {cat, name, price, unit, cap (ຄວາມຈຸພ້ອມກັນ), mins (ເວລາຕໍ່ຄັ້ງ), ing (ເຊື່ອມສະຕ໊ອກ — ມິນິບາ)}; ໃບສັ່ງ `htSvcOrd` {item, bk?, qty, date, start, mins, status:'req|done|void'}. ສັ່ງໃຫ້ແຂກ → ແຖວບິນຫ້ອງ id `hx_so_<id>`; ລູກຄ້າພາຍນອກ (ບໍ່ພັກ) → ບັນທຶກວິທີຈ່າຍ (ຍັງບໍ່ເຂົ້າກະ).
- ຈອງເວລາ: ບໍລິການທີ່ມີ `cap` ກວດຄວາມຈຸຊ້ອນເວລາ (ສະປາ 2 ຕຽງ, ຫ້ອງປະຊຸມ 1, ສະລອຍນ້ຳ 30 ຄົນ).
- ມິນິບາ: ເຊື່ອມສະຕ໊ອກ (ວັດຖຸດິບ) ຕັດເມື່ອສັ່ງ, ຄືນເມື່ອ void.
- ລາຍຊື່ອາຫານເຊົ້າ: ຈາກແຜນລາຄາທີ່ `breakfast=true` ຂອງແຂກທີ່ພັກຢູ່ (ຜູ້ໃຫຍ່+ເດັກ ຕໍ່ຫ້ອງ).

## Global Constraints
- ແຖວທຸກອັນ `id`+`upd`; ບໍ່ລຶບ; ອາເຣໃໝ່ `htSvc htSvcOrd` ໃສ່ `Code.gs`, `app.js BR_RESET` (ກາຕາລັອກ `htSvc` **ບໍ່** reset ໃນສາຂາໃໝ່? — ເຮັດຄືປະເພດຫ້ອງ: reset), `htInit`.
- ສິດ: view `htSvc`; act `htSvcDo` (ສັ່ງ/ເຮັດ), `htSvcCfg` (ແກ້ກາຕາລັອກ — ໃຊ້ `htRate`). ຮ້ານອາຫານ→ບິນຫ້ອງ ໃຊ້ສິດ `pay` ເດີມ.
- ເທສເກົ່າຕ້ອງຜ່ານ (ໂດຍສະເພາະ POS: e2e, sale, daysim, fx*).
